# Design: a page, a component spec, a slide

Pick 3 to 6. Judge the artifact the host names: an HTML file, a spec, a screenshot with a description.

- one-job: the page or component has one primary action and the eye lands on it first
- hierarchy: heading, body and caption are three visibly different sizes; nothing else competes
- states: empty, loading, error and success states are specified (or: not applicable, said so)
- responsive: the layout is described or shown for the narrowest and the widest target width
- accessible: text contrast and focus states meet the standard the brief names (for example WCAG AA)
- tokens: every colour, spacing and font comes from the named design tokens, no new ad-hoc values

Not criteria: "feels generic", "I prefer a different palette", "more whitespace".
